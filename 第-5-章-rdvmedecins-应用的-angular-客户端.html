    6. 第 5 章 - [RdvMedecins] 应用的 [Angular] 客户端

    本章逐个文件地详细讲解本文档随附的 [rdvmedecins-angular-client] 文件夹的内容，采用本课程一贯的格式：逐行编号的源代码，随后是标题为“我们来解读这段代码：”的小节。每个项目文件夹还包含其自己的 README.md 文件。

    6.1. 架构概览

    与原文档一样，客户端采用分层架构，在此我们称之为V-C-Services（视图-控制器-服务）：

    术语上有一点差异值得注意：在 AngularJS 1.x 中，视图（HTML 模板）和控制器（相关联的 JavaScript 类）是两个独立的实体，通过 $scope 相连。在 [Angular] 中，它们合并为一个实体，即组件（见上一章）——因此，在后文中，凡是原文档区分视图和控制器的地方，我们都将简单地称为“组件”。

    与原文档一样，组件绝不直接与服务器通信：这一职责专属于服务层。这是一条同时适用于 AngularJS 1.x 和 [Angular] 的设计原则——它没有改变。

    6.2. 项目树

    该结构直接遵循原文档的流程（登录、选择医生/日期、查看日程、预约），只是在这里组织成了独立的 [Angular] 组件，而不是分开的 AngularJS 1.x 控制器和视图。

    Bootstrap用于所有视图（[node_modules/bootstrap/dist/css/bootstrap.min.css]，在 angular.json 中声明）——这是对 Bootstrap 3 的直接演进，原文档已经使用了 Bootstrap 3。

     ? request.clone({ setHeaders: { Authorization: `Bearer ${token}` } })
     : request;

   return next(requestWithToken).pipe(
     catchError((error: unknown) => {
       if (error instanceof HttpErrorResponse && error.status === 401) {
         auth.logOut();
       }
       return throwError(() => error);
     }),
   );
 };

    我们来解读这段代码：

    • 第 6 行：[export const authInterceptor: HttpInterceptorFn = (request, next) => {] ——在过去的几个版本中，[Angular] 更青睐函数式拦截器（[HttpInterceptorFn]）——即一个简单的函数——而不是早期 [Angular] 版本中基于类的拦截器：编写更简短，注册更简单（见 app.config.ts，withInterceptors([...])）；
    • 第 10–12 行：[request.clone({ setHeaders: { Authorization: `Bearer ${token}` } }) : request;] ——[HttpClient] 请求是一个不可变对象——不能直接修改其请求头，必须创建一个修改后的副本。沿链传递下去的必须是这个副本（requestWithToken），绝不能是未经修改的原始请求；
    • 第 15–18 行：[catchError((error) => { if (error instanceof HttpErrorResponse && error.status === 401) { auth.logOut(); } … })] ——会话期间出现 401 错误意味着令牌已不再有效（已过期，或服务器已重启）：此时客户端会被妥善地断开连接，而不是停留在不一致的状态（表面上已连接，但所有请求都不成功）；
    • 第 19 行：[return throwError(() => error);] ——处理之后，错误被原样重新抛出：拦截器不得向调用方代码隐藏该错误（例如经由 [App] 的 [ScheduleComponent]），而只是在此过程中处理一种特定情况。

    我们本可以手动将 Authorization: Bearer ... 添加到 AppointmentService 的每个方法中。拦截器避免了这种重复：“如何对请求进行身份验证？”这个问题只在一处一次性解决，并将自动应用于将来任何使用 HttpClient 的服务。它在 app.config.ts（见下文）中通过provideHttpClient(withInterceptors([authInterceptor]))注册：没有这一行，该函数虽然存在，却永远不会被调用。

     this.auth.logOut();
     this.doctors.set([]);
     this.clients.set([]);
     this.schedule.set(null);
     this.error.set(null);
     this.slotBeingBooked.set(null);

     this.lastDay = null;

   onSearchSchedule(criteria: { doctorId: number; day: string }): void {
     this.error.set(null);
     this.lastDoctorId = criteria.doctorId;
     this.lastDay = criteria.day;
     this.loadSchedule();

   }

     const slot = this.slotBeingBooked();
     if (slot === null || this.lastDay === null) {
       return;
     }
     this.appointmentService.addAppointment(this.lastDay, choice.clientId, slot.id)
       .pipe(takeUntilDestroyed(this.destroyRef))
       .subscribe({
         next: () => { this.slotBeingBooked.set(null); this.loadSchedule(); },
         error: (err) => this.error.set(String(err.message ?? err)),
       });

   onCloseBooking(): void {

   }

       error: (err) => this.error.set(String(err.message ?? err)),
     });

      });
